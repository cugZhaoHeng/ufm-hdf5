这两行代码在你的代码中起到了**“初始化全局空间边界”**的作用，目的是为了在绘制包含多个不同阶段（Stages）的 3D 裂缝模型时，能够**统一坐标系的比例和范围**。

以下是详细解释：

### 1. 语法解释：为什么用 `np.inf`？
*   `np.inf` 代表“无穷大（Infinity）”。
*   `global_min` 初始化为 `[inf, inf, inf]`，意思是：**“目前还没找到最小值，先把它设为无限大，后面无论遇到什么数字，都会比它小。”**
*   `global_max` 初始化为 `[-inf, -inf, -inf]`，意思是：**“目前还没找到最大值，先把它设为无限小，后面无论遇到什么数字，都会比它大。”**

这是一个非常经典的算法模式，用于在**未知数据集范围**的情况下，通过遍历找到整个数据集合的边界。

### 2. 在代码中的作用
在你的 `for sim_id in sim_ids:` 循环中，程序通过以下逻辑来动态更新这些值：

```python
# 遍历每个阶段的 X, Y, Z 数据，寻找最小值和最大值
global_min = np.minimum(global_min, [np.nanmin(X), np.nanmin(Y), np.nanmin(Z)])
global_max = np.maximum(global_max, [np.nanmax(X), np.nanmax(Y), np.nanmax(Z)])
```

这样做的目的有三个：

#### A. 确保所有模拟阶段“同框且比例一致”
如果你不这样做，Matplotlib 的 `ax.set_xlim` 等函数在每一帧动画时可能会根据当前帧的数据自动缩放（Auto-scaling）。这会导致：
*   **动画跳动**：当裂缝生长时，坐标轴范围随裂缝大小不断变化，看起来非常晃眼。
*   **空间偏移**：如果不同 Stage 的位置不在一起，坐标轴会不断跳转中心点。
通过计算出的 `global_min` 和 `global_max`，你提前确定了**所有裂缝生长空间的总覆盖范围**，并使用：
```python
ax.set_xlim(global_min[0], global_max[0])
ax.set_ylim(global_min[1], global_max[1])
ax.set_zlim(global_min[2], global_max[2])
```
将其固定。这样无论当前动画播放到哪个阶段，背景坐标轴都是**静止且统一的**。

#### B. 统一尺度
在 3D 地质建模中，裂缝可能有深有浅、有长有短。通过获取所有数据的全局最大/最小值，你可以保证在 3D 空间中，裂缝之间的相对位置关系是真实的物理空间关系，而不是相对于当前子集的局部比例。

#### C. 处理多个数据集
你的代码是处理多个 `sim_ids`（多个压裂阶段）。第一个阶段的 X 范围可能是 0 到 100，第二个可能是 200 到 300。如果不初始化全局变量，你就无法在画第一阶段时就确定画布应该有多大。

### 总结
这两行代码是**“预扫描”**机制的起点，作用是：
1.  **扫描所有数据**：找出所有裂缝坐标在 X、Y、Z 三个维度上的最左、最右、最上、最下、最深、最浅的边界。
2.  **锁定画布**：防止动画过程中坐标轴乱跳，保证视觉上的稳定性。
3.  **统一参考系**：确保所有裂缝都在同一个真实的物理坐标系下进行对比观察。
